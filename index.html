Свои

Чаты, фото, планы и документы только для своей семьи. Без рекламы и чужих людей.

Что внутри

  • Семейные чаты и бесплатные звонки внутри приложения.
  • Общий фотоальбом.
  • Неделя семьи: события, кружки детей, списки покупок и дел.
  • Карточка ребёнка: рост, размеры, вишлисты, дни рождения.
  • Документы под отпечатком пальца, видят только родители.

Приложение закрытое: в семью попадают только по приглашению. Бабушкам и детям не нужен ни пароль, ни аккаунт, хватает кода. Родители могут войти через Google, чтобы вернуться в семью с нового телефона.

Сейчас «Свои» доступны для Android по приглашению.
